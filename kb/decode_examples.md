# 考据范例

> 给考据用的模型看：示范怎么从弹幕证据推出一个梗的含义、来源和态度。
> 结论部分由懂梗的人提供并核实过；推理部分示范应该怎么想。

## 方法总结

1. **梗的五类源头**，各有找证据的地方：
   - 选手说的话 / 口癖 / 外语 → 选手国籍、比赛语音（例：波哈）
   - 外貌 / 造型 / 长得像谁 → 选手照片、发型（例：总监、大表哥）
   - 场外新闻 / 爆料 → 转会、队内矛盾报道（例：宫）
   - 具体比赛瞬间 → 赛事 + 地图 + 点位 + 比分（例：三箱）
   - 跨圈事件 + 社区立场 → 同期其他游戏 / 圈子的新闻（例：MBTI）
2. **双关一层层叠加**：读音（监 ← 箭、宫 ← 弓）和字形（MBTI ↔ MIBR）都可以。不认识的词，先试着按音、按形拆开，挂回已知外号。
3. **最显眼的形式不一定是源头**：谐音可以后来补上（「逮虾户」叠在「软脚虾」上）。用最早出现时间判断先后。
4. **音译词要按字面拆开读**：选哪几个字本身就是梗。「逮虾户」既谐音 Déjà vu，又是「逮虾的人家」；拆开后还要判断**立场**：它指虾（NiKo），还是指逮虾的人（赢他的对手）。
5. **外号会带语法变形**：前缀 p / 批 = 当前发挥糟糕，「强」= 发挥出色；叠词（宗宗、尼尼）= 饭圈腔戏仿。遇到「某字 + 已知外号的一部分」，先想是不是状态修饰。
6. **看主流用法，别停在字面**：「爆了」字面是 C4 爆炸，主流用法却是「有人说了敏感话」。最常复制的那几条用法说了算。
7. **态度比指代更重要**：要写清楚这个直播间怎么看它（嘲讽谁、心疼谁、反讽什么），只写「X = Y」不够用。
8. **证据不够就说不够**，把不确定的点列出来交给人确认。

## 范例 1：波哈（选手口癖 / 外语 → 群体代称）

- 证据：最多复制的是纯复读「波哈！😠」；后来出现「小众波哈队」「MBTI 又是哪个波哈队」「波哈基米」；有观众问主播「波哈是什么意思」
- 推理：发音不像中文词，像外语音译；「波哈队」说明它被当成一类队伍的标签 → 查外语脏话 / 口头禅
- 结论：葡萄牙语脏话 porra 的音译，南美选手比赛中常喊，于是「波哈」= 南美选手 / 队伍。「波哈基米」是和「哈基米」拼接
- 方法要点：外来音译词 → 查选手所在地区的语言；「X 队」「X 选手」这种搭配暴露它是群体标签

## 范例 2：总监 / 宫监 / 🏹（外貌 + 场外新闻 → 谐音族）

- 证据：「宫监手！准备放监！🏹」「开宫的欲望正在高涨🏹」带 Twistzz 标签；「《是的，总监！》」
- 推理：「宫监手…放监」读起来是「弓箭手…放箭」，说明「监」「宫」是谐音替换；🏹 跟着出现，是弓箭的符号化；「总监」是核心外号，要单独查来源
- 结论：总监 = Twistzz（发型总监，爱做发型）；宫 = 宫斗（他被爆私下独裁、主导踢人）；宫 + 总监 = 宫监 → 弓箭 → 🏹、开宫
- 方法要点：一个外号确立后，会沿着谐音长出整族词和 emoji；先找族里的核心词，再查核心词的来源

## 范例 3：大表哥（长相 → 外号）

- 证据：「请在烟雾中找出大表哥」「我的青春是大表哥，心中永远的世一指…30 台摄像机专拍」
- 推理：「世一指」= 世界第一指挥，说明是指挥选手；「表哥」暗示和另一个人有「亲戚」关系 → 查是否长得像谁
- 结论：karrigan，因为长得像早期选手 JW（小表哥）
- 方法要点：亲属称谓类外号（表哥、爷爷、宝宝）往往来自长相相似、年龄或角色关系

## 范例 4：三箱 / 软脚虾（具体比赛瞬间 → 长期叙事）

- 证据：「波士顿三箱」；「男人一生只哭 23 次：……波士顿的 niko，斯德哥尔摩的 niko，巴黎的 niko……」；「2 次 major 亚军」；🦐、虾哥、逮虾户
- 推理：「波士顿」是 Major 举办地 → 2018 波士顿 Major；「三箱」像地图点位；一长串城市 + niko 说明是反复的大赛失利 → 「虾」系外号应和失利叙事有关；按时间顺序，「软脚虾」早于「逮虾户」
- 结论：2018 波士顿 Major 决赛，炼狱小镇 B 点三箱，Stewie2k 守住关键一分，NiKo 所在队伍一泻千里。这是「软脚虾」（大场面发挥失常）的起点，虾哥、大虾都由此而来
- 方法要点：城市名 + 选手 → 查该城市举办的大赛；点位名 → 查地图和关键回合；注意区分源头和后来叠加的谐音

## 范例 4.5：逮虾户（音译 + 字面义 + 立场反转）

- 证据：sb6657 有「超级逮虾户战报」，里面是「美味鲜虾点数排行榜」（对位击杀比 NiKo 多 3 个以上的选手得分）和「捕虾战队哪家强：捕虾队评级」
- 推理：「逮虾户」读音像 Déjà vu（又来了），但三个字的字面是「逮虾的人家」；战报里得分的是**赢 NiKo 的人**，捕虾队是**赢 NiKo 的队** → 它指的是猎人，不是虾
- 结论：逮虾户 = 经常战胜 NiKo 所在战队的战队或选手，同时谐音 Déjà vu（又是熟悉的结局）
- 方法要点：容易犯的错是看到和 NiKo 有关，就以为是 NiKo 的外号。要用使用场景（谁得分、谁被嘲）判断立场

## 范例 5：MBTI（跨圈事件 + 社区立场 + 字形双关）

- 证据：最近几天突然大量出现：「赛前没有选手 MBTI，局内赢了不站起来庆祝，好业余的比赛」「MBTI 又是哪个波哈队」「有没有姐妹知道猎小鹰五个宝宝的 MBTI 呀」
- 推理：突然爆发 → 对应最近的事件；「好业余的比赛」是反讽，嘲讽的是「有 MBTI 的比赛」→ 查哪个比赛最近展示了选手 MBTI；「哪个波哈队」→ 把 MBTI 当成南美队名，找字形或读音相近的南美战队
- 结论：VCT CN（瓦洛兰特国内联赛）在赛前展示选手 MBTI。直播间看不上 MBTI 这种标签化、轻浮的话题，也顺带敲打不喜欢的瓦洛兰特。MBTI 和南美战队 MIBR 字形相近，所以被说成「又是哪个波哈队」
- 方法要点：时间上的突然爆发 → 查同期事件，包括别的游戏圈；反讽句要读出真正嘲讽的对象；英文缩写注意字形双关

## 范例 6：批监 / 强肩（状态前缀 + 现成词双关）

- 证据：「《是的，总监！》《对的，披监！》《牛的，强肩！》《卧槽里的，忒丝特ZZ！》」；「总监、披监、宫监都是同一个人」
- 错误的推理（不要这样）：只按谐音找现成词，「披监」≈ 披肩（头发），就停下了
- 正确的推理：几个词都是「某字 + 监」，又都指同一个人 → 前面那个字是修饰。p / 批 是表示「当前发挥糟糕」的前缀，「强」表示发挥出色；披肩、强肩是顺手借的现成词，形成第二层双关
- 结论：批监 / 披监 = 正在拉胯的总监，强肩 = 正在发挥出色的总监（同时是粗俗谐音）
- 方法要点：同一个人的一串外号里，变化的那个字往往是状态修饰，而不是新的含义来源

## 范例 7：宗宗（读音拆字 + 叠词饭圈腔）

- 证据：一半以上带 Team Spirit 标签；「被宗宗爆头」「背锅位帮我选一下宗宗」；「可是宗宗也🥺……太菜了吧😅」「你不能骂宗宗呀，宗宗就被骂的小脑袋特别晕……」
- 推理：是 Spirit 的选手 → 名单里读音对得上的是 zont1x（zon → 宗）；叠词 + 🥺 + 宠溺腔 → 饭圈女戏仿，通常戏仿的是长得好看的选手
- 结论：zont1x，长得帅；「可是宗宗也🥺……太菜了吧😅」= 先饭圈式护短，最后一句翻转吐槽发挥
- 方法要点：叠词外号先想到饭圈腔；配合标签里的队伍名单，按读音找人

## 范例 8：爆了（多义词，看主流用法）

- 证据：「B 区爆蛋辣」「[AI]C4(已深度思考40秒)：爆了」（字面）；「爆了是觉醒者，不爆是正常人，不让爆是罕见」「真爆假爆」「害怕直播间爆了」
- 错误的推理（不要这样）：被字面义带走，认为主要是 C4 爆炸
- 正确的推理：「觉醒者」「罕见」「不让爆」这些词是在评价**言论**，不是在说炸弹 → 「爆」指的是有人发表了激进 / 敏感言论
- 结论：主播或弹幕出现了激进、敏感的言论（影射社会问题、政治、社区冲突等），弹幕就刷「爆了」；C4 爆炸的字面义也会用
- 方法要点：复制最多的那几条里的搭配词（觉醒者、罕见）最能暴露真实用法

## 补充线索（第二批讲解）

- **主播自己的行为和直播间规则也是梗源**：开弹幕等级限制 → 「独裁」「滥权」；主播的身材 → 猪；主播「孝」谁 → 孝。
- **符号替字躲屏蔽**：玩畜 → 玩÷（÷ 读「除」≈「畜」），同一手法移植成「祥➗」。看到符号夹在名字里，先按读音还原。
- **外部固定句式**：心理委员等来自整个中文互联网，不是直播间原创；判断时可以先想「这句在别的地方见过吗」。
- **官方娱乐内容也会造梗**：ESL 发的测谎仪视频 → 「测谎仪：😅」。爆发时间对得上某个官方视频 / 采访，就去查那段时间的官方社媒。
- **同一个词常有一层性暗示**（黏、胶水）。记下来是为了识别，聊天时不要用这一层。
- **不是每个高频词背后都有事件**：G2 只是 2024 年很火。证据里找不到事件，就别硬编一个。

## 范例 9：玩÷（符号替字，由考据者独立推出、经人确认）

- 证据：「玩÷我命令你锤自己」出现在喷主播的语境；「叫小姐太虚伪……晚上好，祥➗」套的是「……晚上好，啥b！」模板
- 推理：÷ 读「除」（chú），和「畜」（chù）几乎同音；直播间本来就有「玩畜」的叫法 → 符号替字，用来躲屏蔽词；同一个模板里「祥➗」= 祥畜，是把手法移植到丰川祥子身上
- 结论：玩÷ = 玩畜；祥➗ = 祥畜

## 范例 10：登山（多源印证 + 事件串联）

- 站内证据：「想登山就直接下播」「播的越多…主播越累，登山概率越大」→ 登山 = 停播；「登山回来的玩÷…憋了一个月攻击性」→ 一次约一个月的停播；「那一天的宫监开弓起来，那一天的机器登山起来…在解除发言限制之前」→ 和宫监、发言限制同时发生
- 外部证据：萌娘百科「玩机器Machine」词条记载 2025 年 2 月 7 日 zews 爆料 Twistzz 宫斗、当晚弹幕攻击 Twistzz、玩机器批评观众后下播、次日道歉停播、复播后开粉丝牌发言 21 级限制
- 来源（由人确认）：他下播后在斗鱼鱼吧发的文章里有「欲渡黄河冰塞川，将登太行雪满山」，原本表达痛苦，后被观众拿来说笑
- 结论：一个事件把几个梗串在一起：宫斗爆料 → 宫监 → 弹幕攻击、主播下播（孝 Twistzz）→ 登山 → 弹幕等级
- 方法要点：
  - 粉丝百科（萌娘百科等）是重要证据源，页面靠 JS 渲染，要用浏览器打开
  - 站内弹幕给「用法」，百科给「时间线」，两边对上才算确认
  - 注意梗背后的真实情绪（这里是心理健康），决定哪些用法不能学
